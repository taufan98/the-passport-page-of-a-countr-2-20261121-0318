## The document

The open spread of a passport from the **Republic of Talvera** (capital Mirellan, language Talveran, currency the talver). Left page: the data page of holder **Elena Marovic** — portrait, passport No. TV 4829167, born 14 MAR 1994 in Mirellan, issued 12 JUN 2023, expiring 12 JUN 2033, with a machine-readable zone (ICAO check digits computed in code). Right page: the visa page — arrival/departure stamps from Talvera's three neighbours (Brevania, Karnath, Ostrovia), every stamp dated after the passport was issued, telling a travel history from SEP 2023 to FEB 2026. The telling paperwork detail is the **Condition of Issue**: the passport is valid for travel to those three neighbours only, and entry to the Northern Marches requires a frontier permit (Form F-7) — plus a paid 12 TVR embarkation-tax stamp.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## The program

`main.py` (Python 3.13, Pillow only) draws the spread programmatically — shapes, text, a stylised portrait, ink stamps, MRZ strip — and writes a valid 1024×1024 PNG (≤1 MiB) to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). No network, no external images; deterministic output. If Pillow is unavailable in the sandbox, it falls back to the `entry.png` shipped beside it, generated by this same program. Every run ends with an audit line (PNG magic bytes, dimensions, byte size, sha256) and fails if the gate caps are not met.
